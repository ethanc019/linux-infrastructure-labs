Final Scenario Summary - Lab 10

Issue:
A Linux web service was unavailable on the affected server.

Evidence:
- Remote SSH access to the server was confirmed.
- apache2 was found inactive.
- curl to localhost failed while the service was stopped.
- journalctl showed Apache service activity.
- Firewall rules were reviewed with UFW.

Action Taken:
- Verified remote admin access over SSH.
- Checked Apache service status.
- Reviewed service logs.
- Reviewed firewall rules.
- Restarted Apache.
- Verified port 80 was listening.
- Confirmed HTTP response returned successfully.

Result:
The web service outage was identified, reviewed, restored, and verified
using Linux administration and troubleshooting commands.
